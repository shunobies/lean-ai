# Memory and Reporting

## scratch_pad (short-term)
Update after:
- file creation
- multiple candidate URLs discovered
- each accept/reject decision batch
- URL-pattern discovery
- crawled result page review
- source switch
- expansion from local radius to nationwide

Keep concise and action-oriented.

## journal (durable)
Update after:
- file creation
- every 5 accepted listings
- every 10 rejected listings
- completion of a major source
- meaningful URL-pattern discovery
- meaningful crawl completion
- search-radius expansion
- before final response

## Final ledger reconciliation
Before final response, update:
- Search Summary
- Current Counts
- Search Notes
- Working Search URLs
- Crawled Pages
- Search Limitation (especially if <25 accepted)
- accepted table numbering
- reviewed-pending cleanup
